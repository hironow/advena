`dayAsIntended` は `single` で成り立ちます。公開時に記録される `pubDay` は、実行が `check` で決めた `day` です。`FIX_DAY = true` なので、`collect` が `storedDay` を `dayFor(arg, today)` で必ず 1 以上の値に固定します。`intendedDay` はこの `storedDay` を返します。

1. **`storedDay` は一度決まると変わらない。**
   - `collect` は `status == "none"` の文書にしか実行できません。
   - どの action も `status` を `"none"` に戻しません。
   - したがって文書は 1 度しか作られず、`storedDay` は固定のままです。
2. **実行の `day` は `storedDay` に一致する。**
   - `afterCheck` は `day: targetOf(d, t)` を設定します。
   - `storedDay != 0` なので、`targetOf` は `storedDay` を返します。
3. **番組は `s1` の 1 つだけである。**
   - ほかの文書の `day` を持ち込む経路がありません。
4. **`publishDoc` は `pubDay` に `runs.get(r).day` を入れる。**
   - これは `storedDay` と等しい値です。
   - 再公開や sweep で `failed` になった後の公開でも、同じ値になります。
   - したがって `status == "created"` のとき、常に `pubDay == storedDay == intendedDay` です。
