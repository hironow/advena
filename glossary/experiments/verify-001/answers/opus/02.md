**答え: 破れます (violated)。**

`FIX_DAY = false` なので、`collect` は同じ日の番組が既にあっても止まりません。`arg = 0` で 2 つの番組を同じ日に収集すると、どちらも番組対象日が 1 日になります。そのため、両方が 1 日の番組として公開されます。

1. `collect("s1", 0, true, false)`: `today = 1`。s1 は `status = creating`、`storedDay = 0`、`items = {1}`、`pending = true` になります。
2. `deliver("s1", "r1")`: r1 が `started` になり、s1 の `pending` は false になります。
3. `check("r1")`: s1 は終了状態ではなく、`targetOf = 1` の項目があります。r1 は `selected`、`day = 1` になります。
4. `writeScript("r1")` → `writeAudio("r1")` → `publish("r1")`: s1 は `created`、`pubDay = 1` になり、r1 は `idle` に戻ります。
5. `collect("s2", 0, true, false)`: s2 は `status = none` なので実行できます。`FIX_DAY` が false なので `dayTaken` は確かめません。
6. `deliver("s2", "r1")` → `check("r1")` → `writeScript("r1")` → `writeAudio("r1")` → `publish("r1")`: s2 も `created`、`pubDay = 1` になります。

この時点で、1 日に `created` の番組が s1 と s2 の 2 つあります。よって `onePerDay` は偽になります。
